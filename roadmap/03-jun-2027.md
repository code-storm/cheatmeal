# June 2027 — H2 Phase 2: First light-social ship; S3/R2 lands; content model locked

**Theme:** turn May's foundations into the first real shipped features.

## Carried-forward risk check-in

Solo-founder bandwidth is why Track A ships exactly one light-social feature and one content pilot this month, in sequence — Track B can afford to run both plus more in parallel.

## Track A — still solo/bootstrapped

- **Ship the first real light-social feature:** a Bump Squad cohort "weekly recap" — a shareable (WhatsApp, reusing H1 Phase 1's share-card pattern) card like "Your Bump Squad completed N tasks this week, you're #K of M." Still read-only aggregation, no chat, no posting, no public profile — this is explicitly the furthest light social goes before hitting the "full social network" line both H1 and H2 rule out.
- **Build the S3/R2 integration** for admin image uploads, replacing `adminUpload.routes.ts`'s local-disk `multer.diskStorage` call with an object-storage-backed upload. This unblocks admin-manageable art for any event or content work for the rest of H2.
- **Lock the postpartum content-model decision** from May's sketch and seed a small opt-in pilot (e.g. postpartum weeks 1–4) as static content, following whichever pattern was chosen. Apply the same `source`-citation trust pattern H1 Phase 2 gave avoid-rules — postpartum/newborn-care content needs the same "why this is on your list" surfacing, since it's outside the pregnancy-week domain H1 originally scoped.

## Track B — if team/funding grows

- Same weekly-recap ship and same S3/R2 build as Track A — if May's S3/R2 ticket is already done on this track, June's capacity goes further: e.g. a second light-social surface such as a "nearest due-date neighbors" opt-in nudge, still backend-only aggregation.
- **Postpartum content pilot ships broader** — more weeks, both diet and recovery-exercise tracks — given more hands to write and review clinically-adjacent content safely. Content accuracy/liability review (flagged as a risk in H1) matters more, not less, as the content surface grows; more hands make a real review step affordable.
- Continue RBAC/multi-admin build-out if a second admin user is now active.

## Metrics

Track A: **~1,250–1,500 WAU**. Track B: **~1,400–1,800 WAU** (the first light-social share surface and a broader postpartum pilot both contribute distinct growth edges).
